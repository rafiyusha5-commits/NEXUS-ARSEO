# Открытые вопросы к ARSEO

Статус документа: черновик. Здесь собраны вопросы, без ответа на которые нельзя окончательно реализовать модель данных, права и процесс. Вопросы, на которые уже есть ответ в задании или в документах репозитория (роли, склады, маршруты, валюты, типы документов, единицы учёта, методы распределения расходов, этапы пилота, роль 1С как источника данных), сюда не включены.

Ссылки на документы: [модель данных](./data-model.md) · [роли и права](./roles-permissions.md) · [процесс RVI](./process-rvi.md).

## 1. Критические до реализации базы данных

| № | Вопрос | Где влияет |
|---|---|---|
| 1.1 | Что такое «проект» (Leib4-x–Leib7-x): группа поставок одного заказа, один заказ производителю или отдельная сущность со своими статусами и расходами? Достаточно ли поля `shipments.project_code`? | `shipments`, отчёты по проектам |
| 1.2 | Верно ли правило «одна поставка = одна перевозка (один автомобиль)»? Как делить позиции заказа между двумя автомобилями и на каком этапе? | `shipments`, `shipment_items`, этап 6 |
| 1.3 | Может ли в одной поставке быть несколько строк одного товара (разные цены, партии, серии)? | уникальность в `shipment_items` |
| 1.4 | Может ли один контрагент быть одновременно, например, поставщиком и клиентом или перевозчиком и брокером? Нужен ли для этого набор типов вместо одного? | `counterparties.type` |
| 1.5 | По какому признаку определять, что контрагент уже есть в базе: БИН/ИНН/VAT, название + страна? Какие форматы идентификаторов нужны для Казахстана, России, ЕС, Турции, Грузии, Кыргызстана? | `counterparties.tax_id`, дедупликация |
| 1.6 | Как формируется внутренний номер партии? Совпадает ли он с серией производителя или ARSEO присваивает свой? | `batches.batch_number` |
| 1.7 | Какие поля карточки товара обязательны для создания товара (например, ТН ВЭД, GTIN, срок годности, температурный режим)? | `products`, этап 1 |
| 1.8 | Есть ли у ARSEO установленный формат номеров поставок, продаж и документов? | `shipment_number`, `sale_number` |
| 1.9 | Хранить ли ФИО и телефоны водителей? Если да — кто их видит и сколько хранить? | `vehicles` |
| 1.10 | Вход в систему — по почте и паролю или через Google-аккаунты компании? | `users.password_hash` |
| 1.11 | Сколько лет хранить журнал действий, закрытые поставки и документы? | `audit_log`, архивирование |
| 1.12 | Бывает ли на одном маршруте (например, Турция → Казахстан) несколько вариантов с разными перевозчиками, сроками, пунктами оформления? | уникальность в `routes` |
