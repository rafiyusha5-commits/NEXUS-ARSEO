# Кабинет внешнего клиента

Миграция `202609273300_external_client_portal.sql` добавляет изолированный кабинет `/portal/documents`. Представитель покупателя получает приглашение на странице `/admin/client-access` и сам задаёт пароль по ссылке из письма.

Доступ состоит из трёх независимых прав: просмотр, скачивание и загрузка. Скачивание требует просмотра. Клиент видит только документы своей компании с признаком `shared_with_counterparty`; внутренние документы и документы других контрагентов база не возвращает. Сотрудник ARSEO открывает или закрывает документ в карточке документа. Каждое открытие, скачивание, загрузка и изменение видимости записывается в `audit_log`.

Загружаемые клиентом файлы проходят те же проверки размера, типа, сигнатуры и безопасного пути Storage, что и внутренние документы. Новые документы получают источник `external_upload`, связаны с компанией пользователя и доступны внутренним сотрудникам по обычным правам документов.

Для включения: применить миграцию, открыть «Доступ клиентов», пригласить представителя покупателя и включить нужные права. Затем открыть карточку внутреннего документа, выбрать покупателя и нажать «Открыть клиенту».
