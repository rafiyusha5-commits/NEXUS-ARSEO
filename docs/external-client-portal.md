# Кабинет внешнего клиента

Миграции `202609273300_external_client_portal.sql` и `202609274200_external_document_security.sql` добавляют изолированный кабинет `/portal/documents`. Представитель покупателя получает приглашение на странице `/admin/client-access` и сам задаёт пароль по ссылке из письма.

Доступ состоит из трёх независимых прав: просмотр, скачивание и загрузка. Скачивание требует просмотра. Клиент получает только сокращённый набор безопасных реквизитов через отдельные RPC и одну опубликованную версию файла. Базовые таблицы документов, история версий, суммы, валюта и служебные поля внешнему пользователю недоступны.

Публикацию выполняет только администратор. Документ должен быть связан с выбранным покупателем. Инвойсы, ручные загрузки сотрудников, импорты и любые сформированные документы с ценами остаются внутренними. Опубликовать можно сформированный системой документ разрешённого типа без цен либо документ, который сам клиент загрузил через портал. При появлении новой версии публикация автоматически снимается до повторной проверки администратором. Каждое открытие, скачивание, загрузка и изменение видимости записывается в `audit_log`.

Загружаемые клиентом файлы проходят те же проверки размера, типа, сигнатуры и безопасного пути Storage, что и внутренние документы. Новые документы получают источник `external_upload`, связаны с компанией пользователя и доступны внутренним сотрудникам по обычным правам документов.

Для включения: применить миграции, открыть «Доступ клиентов», пригласить представителя покупателя и включить нужные права. Затем администратор открывает карточку подходящего документа, выбирает связанного покупателя и нажимает «Открыть клиенту».
