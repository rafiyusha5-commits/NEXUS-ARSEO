# Промо, спецзаказы и низкий ОСГ

Блок хранит версионные коммерческие программы трёх типов: промо, специальный заказ клиента и распределение конкретной партии с низким остаточным сроком годности.

Промо может быть общим или клиентским. После коммерческой проверки и итогового утверждения его прирост переносится в выбранный черновик прогноза продаж. Повторный перенос обновляет ту же строку прогноза, а строка программы сохраняет ссылку на неё.

Спецзаказ всегда относится к клиенту. После утверждения из него создаётся клиентский заказ с теми же товарами, количеством и целевыми ценами. С 17.11.2026 (`202611170200`) целевая цена действует только на согласованное количество строки программы: строка заказа хранит ссылку на строку программы и это количество и не может его превысить; дополнительные штуки добавляются отдельной строкой по цене прайса. Строка без целевой цены получает цену из прайса (`docs/sales-price-list.md`).

Для низкого ОСГ в строке обязательно выбирается конкретный доступный складской остаток. На один товар и единицу в версии хранится одна согласованная партия; повторное сохранение заменяет её. Система проверяет товар, единицу, количество, статус и срок партии, фиксирует рассчитанный ОСГ на дату начала программы. При создании клиентского заказа резервируется именно утверждённая партия с явной причиной отклонения от FEFO. Дальнейшее подтверждение заказа использует существующий контроль гарантийного письма, если ОСГ ниже требования клиента.

Жизненный цикл: `draft` → `in_review` → коммерческая проверка → итоговое утверждение директором → перенос в прогноз или создание заказа. Утверждённые версии не редактируются; для изменений создаётся новая версия.

Администратор видит только реестр и статусы, без товаров, партий, скидок и цен. Прямые записи закрыты RLS и отозванными правами; изменения выполняются только RPC миграции `202609273200_commercial_programs.sql`.
