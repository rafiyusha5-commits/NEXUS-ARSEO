# Откуда взялось количество

Основа: `fix/supplier-quantity-baseline-20261021`, `009a0bedd3a371ceaeee66228e1dae4ca0b040d5` (PR #58).

Отдельная вкладка карточки поставки: **Откуда количество**. Только чтение.
Компонент сверки декларации, операции подтверждения, приёмки, остатки и финансы не меняются.

## Источники и правила

- Текущие количества: существующие `shipment_items`, без выбора запасного количества вместо отсутствующего.
- Первоначальная потребность: существующая INSERT-запись `audit_log` именно этой позиции, только при `audit.view`.
  При разделении по автомобилям это не восстановление первоначального общего заказа. Без записи — «Источник не зафиксирован».
- Подтверждение/отгрузка: `shipment_item_quantity_confirmations`, прежнее/новое значение, сотрудник, время, документ и сохранённая версия.
  Повторное подтверждение того же значения не добавляет событие по существующим правилам.
  Совпавшее старое значение не приписывается текущему: нужна последняя запись. При одинаковом времени нескольких записей источник текущего значения не выбирается произвольно.
- Приёмка: существующие `shipment_transport_receipts` / `shipment_transport_receipt_items`.
  `received_quantity` включает повреждение; годное, повреждение, недостача и излишек показаны раздельно.
- Дельты — только отображение в единице позиции: подтверждение минус текущая потребность; фактическая приёмка минус отгрузка.
  Они не складываются и не создают складскую недостачу. Короба/штуки/кг не суммируются и не пересчитываются.

## Доступ и полнота

`shipment_quantity_provenance(uuid)` — STABLE SECURITY INVOKER, один снимок SQL, RLS всех таблиц и личные запреты сохраняются.
Скалярная JSON-проекция не обрезается PostgREST на 1000 строках. Ошибка запроса даёт сообщение о незагруженных данных, а не пустую «полную» историю.
Вызов доступен только authenticated, не anon/service_role. Новых прав на бизнес-таблицы нет.
Нет цен, тел документов, содержимого аудита, путей Storage, скрытых идентификаторов документов.
Источники отбираются по доступности документа/версии/извлечения и действующей привязке к поставке/нужному автомобилю.
Архивные, отклонённые и отвязанные источники не перечисляются. Историческая версия не становится текущей автоматически.

## Ограничения существующих данных

- Первоначальная потребность без доступной INSERT-записи не восстанавливается.
- Журнал подтверждения не хранит причину и снимок единицы; они не выдумываются.
- Приёмка не хранит прямую связь с документом приёмки: выводится существующая запись приёмки и факт отсутствия связи.
- История скрытого источника не показывается; это не доказательство отсутствия документа.
- Нет экспорта нового блока. Существующий экспорт отчёта не меняется.
- Проверки синтетические; реальные архивы, документы и базы не использованы.
