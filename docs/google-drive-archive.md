# Архив Google Drive: только чтение

Источник: `02_Для дистрибьюторов KZ`, ID `1VRUVM95YlgH4hyzILnC56mq_2Dpw5adm`.
Используется существующий служебный аккаунт Viewer. Отдельный токен получает только scope `drive.readonly`; токен калькулятора сохраняет `spreadsheets.readonly`.
Все обращения к Drive выполняются GET. Единственный POST Google — обмен подписанного JWT на токен в OAuth. Записи, удаления, загрузки, перемещения, комментарии и изменения прав Google отсутствуют.

Применить `202609275800_agent_drive_archive.sql` после 5700. Право `documents.drive.view` первоначально получают администратор и директор по согласованию владельца. Нужны также `documents.view` и `agent.use`. Право открывает весь разрешённый архив, включая прайс-листы; выдавать другим ролям только с пониманием этого охвата. Внешние аккаунты не поддерживаются.

В Nexus: Ассистент → Архив Google Drive. В Telegram: «Найди декларацию соответствия Belgian», затем кнопка «Получить: ДС Belgian.pdf». Кнопка открывает личный чат бота с командой `/start drive_<id>`; после запуска бот повторно проверяет привязку, права и принадлежность файла архиву. Также поддерживается `/file <id>`.

Поиск использует названия и пути. При наличии папки бренда сначала проверяется она; такой результат помечается неполным для всего архива. Для деклараций поиск останавливается после первого подходящего набора файлов. Предел обхода — 100 страниц по 100 записей, глубина 16, результат до 20 файлов. Ярлыки не обходятся. Чужой ID не вызывает чтение чужой папки: сначала проверяется присутствие в разрешённом дереве, затем текущая цепочка родителей. При отзыве прав или переносе файла отправка прекращается.

Файлы до 15 МБ скачиваются в память без сохранения в Nexus и без передачи содержимого OpenAI. Google Docs/Sheets/Slides экспортируются локальному получателю как PDF/XLSX посредством GET export, исходник не меняется. Это не поиск по содержимому: срок действия декларации, её применимость и текст ещё не проверяются.

Получение файла по кнопке не запускает модель и не расходует лимит вопросов. Отправка только в текущий привязанный личный чат, с существующей защитой от повторной обработки и единственной попыткой доставки. Неизвестный исход доставки не повторяется автоматически. Состояние сохраняется в существующих telegram_updates, без содержимого файлов.

Бот по-прежнему работает локально, пока компьютер и Nexus включены. Круглосуточный хостинг отдельно.
