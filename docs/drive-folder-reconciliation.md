# Сопоставление папки поставки

Основа: `d67d3d1eccc5629bb1c1856fdcffc8730b3ccb71`, PR #52 поверх #51.
Применять после #52. Не изменяет Google, документы, версии, распознавание,
подтверждённые реквизиты, склад или финансы. Массовой операции нет.

## Поведение

Используются прежние привязка, полный обход, session gateway, RLS,
`import_shipment_drive_file`, SHA-256 lock и квитанция источника.
Экран различает действующую доступную связь, изменение источника,
отсутствие при полной проверке, точное/возможное совпадение, новый
и неподдерживаемый файл. Ошибка/неполная выборка не показывает частичный
список как полный. Счётчик без связи не означает нехватку обязательных документов.

Имя — лишь предложение. Кнопка «Проверить содержимое» скачивает байты
через прежний GET-only клиент, проверяет сигнатуру и SHA-256 и сохраняет
пару revision/checksum в Nexus. Размер и название не доказывают дубль.
Перевод/скан/оригинал с разными байтами не объединяются по смыслу.
Подпапки служат только фильтром, не определяют тип или участок перевозки.

«Связать с существующим документом» требует выбора и согласия сотрудника,
снова скачивает/проверяет источник, права, принадлежность папке и версию Drive.
В одной транзакции блокируются папка, источник, checksum и документ;
выбранная текущая версия проверяется повторно. Затем используется прежняя
регистрация связи/квитанции. Временный объект Storage для этого действия не нужен.
Новая версия, архивный/отклонённый/недоступный документ или снятая связь
блокируют действие. Ручные подтверждения не изменяются.

Кандидаты строятся только из доступных session-RLS документов и их текущих версий.
В браузер не передаются checksum, скрытые ID и старая квитанция скрытого документа.
Отдельно показаны одобрение документа и доступное подтверждение чтения
текущей версии для этой поставки.

## Ограничения

- Реальные документы и реальные Drive/OCR не проверялись.
- Лимиты прежнего обхода сохранены: 500 файлов/50 страниц/90 секунд, до 4 МБ.
- Проверка содержимого — по одному явно выбранному файлу, не массовое скачивание.
- Если уже существуют несколько доступных документов с одним SHA-256 и прежний
  механизм выбирает не указанный документ, транзакция отказывается без изменений;
  конфликт требует отдельного разбора, автоматического слияния нет.
- Между последним Drive GET и транзакцией Nexus остаётся межсистемное окно:
  атомарной транзакции с Google нет. Сохранённые подтверждения не заменяются.
- Windows build может завершиться ошибкой обработки Jost в `next/font`/Turbopack;
  итог сборки Linux указывается по фактическому CI. Локальный Docker недоступен;
  WASM SQL smoke не считается проверкой PostgreSQL 16.
- Миграция `202610200100_drive_folder_reconciliation.sql` добавляет два nullable
  поля проверенного содержимого и два invoker RPC; новых прав ролям и
  service_role не выдаёт. Никакой backfill, очистки или расписания.
