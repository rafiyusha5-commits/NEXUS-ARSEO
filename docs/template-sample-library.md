Файлы этой папки являются конфиденциальными рабочими образцами. Они не копируются в репозиторий, публичные хранилища или тестовые данные. В репозитории хранится только этот реестр назначения файлов. Оригиналы используются только для анализа структуры и подготовки управляемых версий шаблонов в приватном хранилище Nexus-ARSEO.

## Правила использования

1. Оригинал никогда не перезаписывается. Для адаптации создаётся отдельная рабочая копия и новая версия шаблона.
2. Клиентский файл используется только для указанного покупателя. Общим он становится только после отдельного решения ARSEO.
3. Для новой экспортной отгрузки книга `Отгрузка заказ HS-41.1 Fazer.xlsx` является эталоном источников и расчётов для CMR, ТТН и упаковочного листа.
4. PDF `CMR.pdf`, `ТТН.pdf` и `упаков.лист.pdf` являются контрольными образцами результата: по ним проверяются состав полей, печатная форма и итоговые значения.
5. Карта ввода означает листинг нового товара у покупателя. Карта вывода означает делистинг товара. Тип карты хранится явно и не определяется только по имени файла.
6. Гарантийное письмо формируется при отгрузке товара с низким остаточным сроком годности. Порог не зашивается одним числом: он должен настраиваться для покупателя или договора, обычно в диапазоне **50–60%**.
7. Образцы ТОО `Jibek Joly Co` сохраняются как исторические документы. Они не назначаются активным шаблоном ARSEO и не используются для новых прямых контрактов ARSEO.
8. При добавлении файлов в локальную папку реестр дополняется новой строкой с датой, размером и контрольной суммой. Замена файла с тем же именем считается новой версией.

## Технические ограничения, учтённые при приёмке

- Текущий генератор Nexus-ARSEO автоматически заполняет только DOCX. Для экспортного комплекта и клиентских карт потребуется поддержка XLSX с сохранением формул, объединений, изображений, проверок данных, областей печати и последующим контролируемым экспортом в PDF.
- `Карта ввода Метро.xlsb` пока не поддерживается текущим валидатором файлов. Рабочая копия должна конвертироваться в XLSX в настольном Excel с проверкой формул и печатного вида; исходный XLSB остаётся эталоном.
- Файлы XLS и XLSX нельзя пересохранять библиотекой, которая удаляет неподдерживаемые расширения Excel. При автоматизации сложных книг сначала выполняется сравнение структуры и визуальный контроль результата.
- Порог ОСГ, набор обязательств и текст письма зависят от покупателя и договора. Система должна получать эти правила из настроек контрагента, а не из имени образца.

## Приёмка новых образцов

При каждом пополнении папки:

1. определить класс документа, покупателя/поставщика, направление и активность;
2. зафиксировать размер, формат, число листов/страниц и SHA-256;
3. проверить, содержит ли файл формулы, скрытые листы, изображения, макросы или внешние связи;
4. определить входные данные и ожидаемый выход;
5. сохранить оригинал как неизменяемый эталон;
6. создать адаптированную версию для Nexus-ARSEO только после сопоставления полей;
7. сравнить сформированный документ с эталоном визуально и по контрольным итогам.
