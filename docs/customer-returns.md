# Возвраты от покупателей

Миграция `202609277500_customer_returns.sql`. Раздел «Продажи → Возвраты» (`/sales/returns`) и вкладка «Возвраты» в заказе покупателя.

## Порядок

1. **Оформление.** По отгруженному заказу сотрудник с правом `sales.returns` указывает, сколько вернул покупатель по каждой отгруженной партии, и причину: брак, повреждение, срок годности, пересорт, отказ клиента, другое. Вернуть больше, чем отгружено по позиции и партии (за вычетом прежних возвратов), нельзя. Количество — в единице заказа; для отгрузки из остатка в других единицах отгруженное пересчитывается через упаковку товара.
2. **Карантин.** Возвращённый товар не попадает в свободный остаток: его нельзя зарезервировать или продать. Возврат имеет статус «В карантине», пока по каждой позиции не принято решение.
3. **Решение** по каждой позиции:
   - **Вернуть в продажу** (`inventory.receive`) — движение «Возврат от клиента» (`customer_return`) в ту же партию на склад заказа, при желании в выбранную зону. Партия, которая была полностью израсходована, снова становится доступной; партия на карантине или заблокированная сохраняет свой статус.
   - **Списать** или **Вернуть поставщику** (`inventory.write_off`) — с обязательной причиной; в свободный остаток товар не попадает.
   Когда решения приняты по всем позициям, возврат закрывается.
4. **Отмена** — с причиной и только пока ни по одной позиции нет решения; отменённый возврат снова освобождает количество для возврата.

Каждая позиция хранит цену заказа: сумма возврата уменьшает долг покупателя (учитывается в дебиторке).

## Права и данные

- Видеть возвраты — `sales.view`. Оформить и отменить — `sales.returns` (администратор, директор, исполнительный и коммерческий директор, директор по логистике, старший менеджер по логистике).
- Таблицы `customer_returns` и `customer_return_items` доступны только на чтение; изменения — функциями `create_customer_return`, `decide_customer_return_item`, `cancel_customer_return`. Изменения пишутся в журнал аудита.
- Отгруженное количество берётся из исполненных резервов заказа (`inventory_reservations.status = 'fulfilled'`), которые проставляет отгрузка заказа покупателю.
