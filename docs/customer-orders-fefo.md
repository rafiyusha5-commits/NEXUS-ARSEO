# Клиентские заказы, FEFO и контроль ОСГ

Миграция `202609272500_customer_orders_fefo.sql` добавляет клиентские заказы, позиции заказов, резервы по партиям и гарантийные письма. В интерфейсе раздел доступен по адресу `/sales`.

## Рабочий порядок

1. Сотрудник создаёт заказ, выбирает клиента, склад и плановую дату отгрузки.
2. Для каждой позиции система сохраняет требуемый остаточный срок годности. Если значение не введено, оно берётся из карточки клиента.
3. Команда «Резервировать по FEFO» атомарно закрепляет доступный товар, начиная с партии с ближайшим сроком годности. Заблокированные, карантинные и истекающие до даты отгрузки партии исключаются.
4. Если одной партии недостаточно, резерв делится между несколькими партиями. При нехватке общего остатка транзакция полностью отменяется.
5. Ручной выбор партии требует права `sales.override_fefo`, причины и фиксирует согласовавшего пользователя.
6. ОСГ вычисляется на плановую дату отгрузки: `(срок годности − дата отгрузки) / полный срок годности × 100`. Полный срок берётся между датой производства и сроком годности, а при отсутствии даты производства — из карточки товара.
7. Если фактический ОСГ ниже требования клиента, заказ нельзя подтвердить без гарантийного письма в статусе `approved`, `sent` или `accepted`.
8. При отмене заказа все активные резервы освобождаются в той же транзакции.

Гарантийное письмо в этом блоке является контролируемой записью и снимком проблемных партий. Формирование файла по утверждённому шаблону будет подключено в блоке 3C вместе с CMR, ТТН и другими документами поставки.

## Права

- `sales.view` — просмотр заказов и резервов;
- `sales.manage` — создание, подтверждение и отмена заказов;
- `sales.reserve` — автоматический FEFO-резерв;
- `sales.override_fefo` — ручной выбор партии с причиной;
- `guarantee_letters.manage` — создание и движение гарантийного письма по статусам.

Таблицы доступны сотрудникам только на чтение через RLS. Все изменения выполняются транзакционными RPC-функциями с проверкой прав.
