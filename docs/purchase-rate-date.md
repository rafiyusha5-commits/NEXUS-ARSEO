# Курс закупки

Решение владельца от 14.10.2026: валютная закупочная цена пересчитывается на дату подтверждённой таможенной декларации. Отдельный тип документа «Таможенная декларация» позволяет указать дату и привязать документ к машине или поставке. Общий тип «Таможенный документ» автоматически декларацией не считается.

Декларация конкретной машины имеет приоритет. Документ поставки применяется ко всем её позициям, если он не ограничен привязкой к другой машине. Несколько действующих деклараций с разными датами требуют уточнения привязок. Архивные, отвязанные, неподтверждённые документы не используются.

Без декларации доступен только предварительный расчёт по текущему курсу, утверждение запрещено. В одной валюте конвертация не требуется. Стоимость товара, уже внесённая отдельным расходом, берётся из распределения этого расхода без повторного включения закупочной цены.

Изменение декларации, её привязки или курсов делает черновик неактуальным. Расчёт и утверждение блокируют параллельную запись этих данных до конца транзакции. Изменение любой записи справочника курсов консервативно требует нового расчёта. Ранее утверждённые версии не переписываются.

Себестоимость партии из нескольких приходов (машин или поставок) — средневзвешенная по приходам, миграция `202611160100` (решение владельца от 16.11.2026, заменяет PR №36). Курс каждого прихода определяется по правилу выше, для каждой позиции поставки отдельно: две машины с разными декларациями дают партии разные курсы в своих долях. Старые партии автоматически не пересчитываются. Правило количества и брака не меняется.
