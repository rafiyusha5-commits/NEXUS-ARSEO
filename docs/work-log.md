  RPC; выполнение через штатный confirm_customer_order, без отгрузки, оплаты

- Права/снимок повторно проверяются после ожидания блокировок. Тесты: точное

  кредитный лимит, откат, повтор после отгрузки. Настоящие конкурентные сеансы:
  повторы, две вкладки, отмена, отзыв письма и права во время lock wait.
- Typecheck, lint, 785 unit-тестов, production build и браузер 1440/390
  с синтетическим HTTP прошли. Локально прошли 96 SQL-файлов и все Node
  concurrency helpers на PostgreSQL16.15, отчёт nexus-assistant-pg16-h5Fg1q.
  Фактический CI последнего коммита фиксируется в PR. Первый локальный SQL-прогон
  остановился на одинаковой почте двух тестовых сотрудников: фикстура
  изолирована, бизнес-правила не ослаблялись.
  Второй прогон выявил неполную подготовку конкурентной фикстуры: остаточные
  штуки ранней FEFO-партии требовали письма для следующего заказа. Тест теперь
  оформляет его штатными операциями, вместо ослабления проверки ОСГ.
- Frontend-design использован для явного отделения подтверждения от отгрузки
  в прежнем оформлении. Живая LLM и полный авторизованный UI+БД E2E не проверены.
  Реальные базы, Google, сервисы, main не менялись; миграции не применялись
  владельцу, флаг выключен, PR не объединён. Приёмка/возвраты пока не подключены.
  Ограничения/пересечения и порядок применения — assistant-confirmed-operations.md.

## 23 октября 2026 — команды ассистента, первый сквозной сценарий

- Владелец согласовал отдельную копию и ветку от
  `7c653ae51e8f17233de518e7fae86def299e2db4`.
- Ветка `feature/assistant-confirmed-operations`. Общая цель — любые штатные
  операции после подтверждения; в этом первом этапе подключено только
  перемещение одного товара между складами. Не считать весь запрос выполненным.
- Общий контракт предложения, отдельный просмотр/подтверждение, сохраняемая
  квитанция, существующий складской документ и RPC, без инструментов записи у
  модели. Google Drive/Sheets только чтение. Новые права service_role не выдаются.
- Проверки: typecheck, lint, unit, build; синтетический SQL на одноразовом PG16.15,
  повтор миграции, чужой автор/личный запрет, упаковка/устаревание, 12 параллельных
  повторов и гонка двух сотрудников за последний остаток. Интерактивный компонент
  в браузере 1440/390 с подменным HTTP: потерянный ответ и перезагрузка.
  Итоговые результаты последнего коммита и CI — в Draft PR.
- Локальный SQL runner нормализует CRLF в LF при подаче SQL: старые миграции
  сравнивают определения функций текстом. Первые прогоны остановились на этом и
  ошибках синтетической фикстуры; не выдавать их за успешный полный прогон.
- Миграция `202610230100_assistant_operations.sql` подготовлена, не применена к
  рабочей или учебной базе. Включение через `AGENT_OPERATIONS_ENABLED`, по
  умолчанию выключено. Не менялись сервисы, секреты, расписания и main.
- Ограничения/следующие операции и пересечения: [описание этапа](assistant-confirmed-operations.md).
  Новая интеграция не проверена с живой LLM, реальными документами и в запущенном
  приложении владельца. Другие действия не разрешены через произвольный RPC.
