# Отчёт по поставке

Экран `/shipments/{id}/report` собирает в одном месте карточку поставки, автомобили, этапы RVI, заказанные и принятые количества, партии, связанные документы и доступные пользователю открытые задачи.

Контроль остатков считается успешным, когда сумма принятого количества совпадает одновременно с количеством, распределённым по партиям, и приходными движениями склада. Расхождение выделяется в отчёте и переносится в XLSX.

Кнопка «Скачать XLSX» формирует файл с листами «Сводка», «Позиции», «Этапы», «Партии», «Документы» и «Задачи». Файл создаётся на сервере из данных, доступных текущему пользователю по RLS. Цены включаются только для руководителей, бухгалтерии и старшего менеджера по логистике; для маркетолога и специалиста по логистике столбец цены отсутствует и на экране, и в XLSX.

Список задач также подчиняется `tasks.view` и правилам видимости задач. Поэтому пользователь видит в отчёте только те открытые задачи, которые доступны ему в разделе «Задачи».

## Итог поставки: весь путь товара

Отчёт заканчивается блоками о том, что стало с товаром после приёмки (`src/lib/shipment-outcome.ts`, правила — `src/lib/shipment-outcome-rules.ts`):

- **Итог поставки** — сколько принято на склад, отгружено и продано, списано, сколько на складе и в резерве (по единицам измерения); сходятся ли движения с остатками; себестоимость; итог «Сверки»; худшее состояние по «Контролю ОСГ».
- **Куда ушли партии** — каждая партия поставки (партии, созданные приёмкой её позиций): срок годности и остаточный срок (по той же формуле, что `private.sale_shelf_life_pct`), риск «Контроля ОСГ», принято, отгружено (складской расход), списано, корректировки, на складе, в резерве и покупатели — заказы, в резерве или отгрузке которых участвует партия. Перемещения между складами не меняют итог. Строка подсвечивается, если приход минус расход не равен остатку партии.
- **Себестоимость** — утверждённый расчёт (если утверждённого нет — последний черновик с пометкой): товар, расходы, себестоимость поставки и каждой позиции за единицу.
- **Итог сверки документов** — замечания агента «Сверка» на сегодня с указанием автомобиля и документа.

Каждый блок читается с правами сотрудника, без service_role:

| Блок | Нужные права |
|---|---|
| Движение партий | `inventory.view` |
| Покупатели партий | дополнительно `sales.view`; клиент без доступа показывается как «клиент скрыт» |
| Себестоимость | `costing.view` и `prices.purchase.view` |
| «Сверка» | `documents.view` |
| «Контроль ОСГ» | `inventory.view` и `products.view`; клиенты без доступа скрыты так же, как на странице контроля ОСГ |

Блок без прав показывается как «Нет доступа», а не как пустой. В XLSX добавлены листы «Итог», «Движение партий», «Себестоимость» и «Сверка»; листы «Себестоимость» и «Сверка» появляются только при соответствующих правах.

Страница отчёта больше не расширяется широкими таблицами: они прокручиваются внутри своей рамки (`.report-workspace{min-width:0}`), а строки списков на телефоне выстраиваются в одну колонку.
