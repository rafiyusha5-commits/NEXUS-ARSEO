# Отчёт по поставке

Экран `/shipments/{id}/report` собирает в одном месте карточку поставки, автомобили, этапы RVI, заказанные и принятые количества, партии, связанные документы и доступные пользователю открытые задачи.

Контроль остатков считается успешным, когда сумма принятого количества совпадает одновременно с количеством, распределённым по партиям, и приходными движениями склада. Расхождение выделяется в отчёте и переносится в XLSX.

Кнопка «Скачать XLSX» формирует файл с листами «Сводка», «Позиции», «Этапы», «Партии», «Документы» и «Задачи». Файл создаётся на сервере из данных, доступных текущему пользователю по RLS. Цены включаются только для руководителей, бухгалтерии и старшего менеджера по логистике; для маркетолога и специалиста по логистике столбец цены отсутствует и на экране, и в XLSX.

Список задач также подчиняется `tasks.view` и правилам видимости задач. Поэтому пользователь видит в отчёте только те открытые задачи, которые доступны ему в разделе «Задачи».
