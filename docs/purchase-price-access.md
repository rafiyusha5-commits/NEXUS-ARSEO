# Доступ к закупочным ценам

`prices.purchase.view` отделяет коммерчески чувствительные закупочные данные от обычного доступа к товарам, поставкам и складу.

По умолчанию право получают директор, исполнительный и коммерческий директора, директор и старший менеджер по логистике, бухгалтер и администратор. Специалист по логистике и маркетолог его не получают. Персональный запрет действует поверх роли.

Право защищает базовую закупочную цену товара, цену позиции поставки, ценовые условия договора, стоимость товара в расходах и рассчитанную себестоимость партии. Эти поля исключены из прямой выборки смешанных таблиц и выдаются только защищёнными RPC. Создание и изменение закупочной цены также проверяются в базе.

Продажные цены из прайса доступны всем сотрудникам в рамках обычных прав на продажи. Загруженные инвойсы и другие внутренние файлы доступны сотрудникам с правом на документы, даже если внутри есть цены. Клиентам и другим внешним пользователям такие файлы не выдаются. В портал можно опубликовать только сформированный системой документ разрешённого типа без цен либо документ, который сам клиент передал через портал. Публикует одну проверенную версию администратор, и документ должен быть связан с этим клиентом.
