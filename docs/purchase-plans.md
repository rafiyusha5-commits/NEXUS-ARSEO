# План закупок

План закупок создаётся для одного прямого поставщика на основании утверждённой версии прогноза продаж. Строки фиксируют спрос из прогноза, снимки остатков и товара в пути, ручной страховой запас, ожидаемые потери по сроку годности и упаковочную кратность.

Автоматическая формула рекомендуемого количества пока не применяется: поле `suggested_quantity` заполняется ответственным сотрудником. `rounded_quantity` рассчитывается базой вверх до указанной кратности, а утверждаемое количество обязано быть кратно упаковке.

Жизненный цикл: `draft` → `in_review` → логистическая проверка → итоговое утверждение директором → `ordered`. Утверждённая версия не редактируется. Из неё создаётся новая версия либо поставка RVI со всеми строками плана. Каждая строка получает ссылку на созданную поставку.

Администратор видит только реестр и статусы. Детали доступны бизнес-ролям. Создание поставки дополнительно требует обычного права `shipments.create`.
