# Поставщики, покупатели и ассортимент

В Nexus-ARSEO поставщик — это завод-производитель, работающий с ARSEO по прямому контракту. При создании товара завод выбирается один раз и одновременно становится производителем и активным поставщиком товара.

Связь хранится в `product_suppliers`. Активной у товара может быть только одна связь, и она обязана совпадать с `products.manufacturer_id`. Прежние дистрибьюторы и старые связи сохраняются со статусом `inactive`: они видны в истории, но не участвуют в новых закупках.

Эта связь используется в трёх местах:

- в поступлении сотрудник видит только товары выбранного завода;
- в плане закупок можно добавить только товары выбранного завода;
- в карте ввода поставщика доступны только товары этого завода.

Ограничение проверяет сама база данных. Добавить в импортную поставку товар другого поставщика прямым запросом также нельзя.

Покупатели и поставщики имеют отдельные реестры:

- `/counterparties` — покупатели;
- `/suppliers` — прямые поставщики, то есть заводы-производители.
