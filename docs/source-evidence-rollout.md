## Проверки

На той же основе: typecheck, lint, 681 тест, production build прошли. Локальная сборка использует кэш файлов шрифтов. Новая регрессия выполняет настоящие страницу отчёта и обработчик XLSX с подменённым источником данных, проверяет пустые значения и явный ноль.

Для SQL-части на PostgreSQL 16 прошли 81 миграция, повторное применение и 72 SQL-файла; отдельно проверены гонки отвязки/подтверждения, отклонения/подтверждения и позднего OCR старой версии. После этого SQL не менялся. Миграция применена только к учебному проекту. CI для пакета проверяется отдельно на опубликованном коммите.

В учебном интерфейсе повторены распознавание комплекта, сверка товарных строк, ручное исправление CMR и итоговый отчёт. Складские движения и себестоимость при ручной сверке CMR не изменялись. Учебная приёмка, сроки партий и часть расходов остаются допущениями.
