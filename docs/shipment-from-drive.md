# Поставка из папки заказа на Google Drive

Экран `/shipments/from-drive` (кнопка «Создать из папки заказа на Drive» в разделе поставок).

1. **Папка заказа.** Nexus показывает папки из «Будущих заказов» (корень `FUTURE_ORDERS_DRIVE_ROOT`).
   Уже привязанные к поставке папки ведут на эту поставку. Папку из архива можно открыть по ссылке —
   она должна лежать внутри одного из двух разрешённых деревьев Drive.
2. **Карточка.** По названию папки и её вложенных папок предлагаются:
   - код проекта — коды заказов из названия (`AB-50`, `Cdx12` → `Cd-12`; номер архива `04_03_` отбрасывается);
   - клиент — по справочнику префиксов, если клиент один; свои склады — без клиента;
   - поставщик — если отличительное слово его названия есть в названии папки и такой поставщик один;
   - маршрут и валюта — как в последней поставке этого поставщика; маршрут иначе — единственный из его страны в KZ;
   - склад — Актобе.
   Всё можно изменить. Ничего не сохраняется до нажатия кнопки.
3. **«Создать поставку и привязать папку».** Создаётся поставка с номером и этапами (`create_shipment_with_stages`)
   и привязка папки (`bind_shipment_drive_folder` через серверный шлюз Drive). Если привязка не удалась, поставка
   остаётся, а экран документов предлагает привязать папку по ссылке.

Документы из папки этот шаг не загружает: их проверка и загрузка — на вкладке «Документы» поставки.
Google Drive только читается (GET, `drive.readonly`).

## Префиксы заказов

Таблица `public.order_prefixes` (миграция `202611220200_order_prefixes.sql`): префикс (1–12 латинских букв, без учёта
регистра), клиент или признак «свои склады», примечание. Читается с `shipments.view`, меняется функциями
`set_order_prefix` / `remove_order_prefix` с `shipments.create`. Список вносится на экране, не в миграции.

## Права

Создание из папки требует прав привязки папки (`shipments.view`, `shipments.update`, `documents.view`,
`documents.drive.view`, `prices.purchase.view`) и `shipments.create`.

## Проверки

`tests/shipments/drive-order.test.ts` — разбор названий на синтетических примерах;
`supabase/tests/order_prefixes.test.sql` — права, проверки и замена префикса без учёта регистра.
