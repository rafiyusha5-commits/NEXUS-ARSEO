# Реестр интеграций и синхронизаций

Миграция `202609272800_integration_registry.sql` создаёт безопасную основу фазы 6. Раздел **«Интеграции»** показывает подключения, запуски, ошибки и ручные сопоставления.

- В `integrations.config` разрешены только несекретные настройки. Ключи, пароли и токены отклоняются и должны храниться только в серверных переменных окружения.
- 1С «Бухгалтерия» и «Управление торговлей» всегда работают только на чтение из 1С в Nexus.
- Запуски и ошибки записывают только доверенные серверные задания через RPC для `service_role`.
- Повторное сопоставление одной внешней записи обновляет существующую связь и не создаёт дубль.
- Неоднозначные совпадения остаются открытыми, пока сотрудник не выберет товар или контрагента вручную.

## Google Drive и Google Sheets

Все таблицы, файлы и папки Google Drive проекта подключаются строго в режиме **только чтение** с правами `Viewer` и read-only scopes. Nexus может просматривать, скачивать и считывать их содержимое, но не может создавать, загружать, изменять, переименовывать, перемещать, копировать или удалять объекты, добавлять комментарии либо менять права доступа. Обратная запись статусов, журналов и результатов обработки в Google запрещена. Все преобразования и результаты сохраняются только в базе или инфраструктуре Nexus. Если источник нельзя прочитать без прав записи, синхронизация должна завершиться ошибкой.

Мастер-калькулятор закреплён за книгой `1VO6lGgt4-qa9NdPVBPjqO15ssNr67wdXE2yJxkDPmFw`, листом `расчеты`. Сервер использует Google Sheets Values API только методом `GET` и scope `spreadsheets.readonly`. Доступ выдаётся служебному аккаунту с ролью `Viewer`; ручная загрузка Excel-копии калькулятора в Nexus отключена.

Подключение конкретных API выполняется после решений И1–И9 и выдачи служебных доступов. Интерфейс никогда не показывает секреты.
