# Реестр интеграций и синхронизаций

Миграция `202609272800_integration_registry.sql` создаёт безопасную основу фазы 6. Раздел **«Интеграции»** показывает подключения, запуски, ошибки и ручные сопоставления.

- В `integrations.config` разрешены только несекретные настройки. Ключи, пароли и токены отклоняются и должны храниться только в серверных переменных окружения.
- 1С «Бухгалтерия» и «Управление торговлей» всегда работают только на чтение из 1С в Nexus.
- Запуски и ошибки записывают только доверенные серверные задания через RPC для `service_role`.
- Повторное сопоставление одной внешней записи обновляет существующую связь и не создаёт дубль.
- Неоднозначные совпадения остаются открытыми, пока сотрудник не выберет товар или контрагента вручную.

Подключение конкретных API выполняется после решений И1–И9 и выдачи служебных доступов. Интерфейс никогда не показывает секреты.
